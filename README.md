# What The Hill Frontend

The frontend (admin and public) for What The Hill.

## Local Development

Tools:

- node/npm/nvm
- NextJS
- MUI
- Zustand
- TailwindCSS

Ensure the `what-the-hill-api` project is running locally.

`npm install`

`cp .env.template .env`

Edit your new `.env` to contain a reference to where your `what-the-hill-api`
is listening.

`npm run dev`
